# Flask-сайт с SQLite

Небольшой сайт на Flask, показывающий результат SQL-запроса к базе SQLite в виде таблицы.

## Запуск

1. Создайте и активируйте виртуальное окружение:

   ```bat
   py -m venv .venv
   .venv\Scripts\activate
   ```

2. Установите зависимости, укажите путь к своему файлу SQLite и запустите приложение:

   ```bat
   pip install -r requirements.txt
   set "SQLITE_DATABASE=C:\путь\к\вашей\database.db"
   flask --app app run --debug
   ```

3. Откройте в браузере http://127.0.0.1:5000.

`SQLITE_DATABASE` принимает абсолютный путь к существующему файлу SQLite. Для относительного пути используется корень проекта, например:

```bat
set "SQLITE_DATABASE=data\company.db"
```

По умолчанию путь к базе указан в `globals.py`. Переменная среды `SQLITE_DATABASE` имеет приоритет и позволяет не менять файл проекта.

Приложение открывает базу только для чтения: не создаёт таблицы и не изменяет записи. На странице «Таблицы» можно выбрать любую пользовательскую таблицу базы. Для выбранной таблицы выполняется запрос `SELECT * ... LIMIT 100`.

На вкладке «Свой запрос» можно выполнить один запрос, начинающийся с `SELECT` или `WITH`. Операции изменения данных запрещены дополнительно и соединением SQLite, и проверкой приложения. В результатах отображаются первые 100 строк.

## Проверка

```bat
.venv\Scripts\python.exe -m unittest discover -s tests
```
