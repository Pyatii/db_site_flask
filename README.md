# Flask-сайт с SQLite

1. Создайте и активируйте виртуальное окружение в терминале VS code:

   py -m venv .venv
   .venv\Scripts\activate


2. Установите зависимости, укажите путь к своему файлу SQLite и запустите приложение:
   pip install -r requirements.txt
   в файле globals.py укажите абсолютный путь к вашей БД (используйте / для разделения)

3. Откройте в браузере http://127.0.0.1:5000.
